# 🐹 SqueekRun: Crystal Caverns

A playful browser platformer and mining-colony game inspired by Squeekchain.

## Play
The playable prototype is being prepared for GitHub Pages/Vercel deployment. Until `index.html` is added, this repository is a development workspace.

## Gameplay
- Move with **A/D** or **←/→**
- Jump with **Space** or **↑**
- Dash with **Shift**
- Pause with **P**
- Collect crystals, dodge cave hazards, and upgrade your mining colony.

## Tokenomics and transparency
**All in-game SQK is simulated.** It is not an on-chain token, has no cash value, and cannot be withdrawn. Mining-power and reward-sharing mechanics are inspired by Squeekchain's documentation, while crystal collection, colony upgrades, and other arcade mechanics are original gameplay systems. No live blockchain data is currently connected.

Documentation: https://docs.squeekchain.com/
